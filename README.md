# Music Finder Bot

Telegram-бот: поиск песен, эффекты, редактор тегов и посты в канал.

## Как бот определяет, что делать

| Что прислали | Что делает бот |
|---|---|
| Аудиофайл (mp3, m4a, wav...) | Меню эффектов (speed up / slowed, reverb, 8D) и изменение тегов |
| Голосовое, видео, кружок | Находит песню (Shazam) и присылает аудиофайл |
| Ссылка (YouTube, TikTok, Instagram...) | Находит песню и присылает аудиофайл |
| Текст | Сразу присылает найденный трек аудиофайлом, под ним кнопки с другими вариантами |
| Картинка с подписью после аудио | Быстрая смена тегов и обложки: подпись `Исполнитель - Название`, картинка станет обложкой |
| `/start` | Меню функций |
| `/circle` | Режим «видео в кружок»: следующее присланное видео станет кружком Telegram |
| `/donate` | Ссылки для поддержки проекта |
| `/post` | Пост в канал с кнопками |

Под каждым присланным треком стоит подпись со ссылками на каналы (см. `CAPTION` в начале `bot.py`).

## Эффекты и теги

- **Скорость**: пресеты 0.5x–0.9x (slowed), 1.1x–2x (speed up) или своё значение от 0.25 до 3. Тон меняется вместе со скоростью, как в обычных slowed / sped up ремиксах.
- **Reverb** и **8D** (лучше слушать в наушниках). Эффекты можно комбинировать.
- **Теги**: при загрузке аудио бот берёт название и исполнителя из файла (или из имени файла вида `Исполнитель - Название`) и сохраняет их в результате. Кнопка «🏷 Теги» меняет их, можно и без эффектов.
- **Обложка**: кнопка «🖼 Обложка», затем картинка (фото или файл). Бот обрезает её до квадрата, вшивает в mp3 и ставит миниатюрой в Telegram. Если обложку не менять, остаётся та, что была в файле.
- У найденных треков обложка ставится автоматически (из Shazam или с источника).
- Результат приходит в mp3 с теми же (или изменёнными) названием и исполнителем.

## Кружки

Кнопка «⭕ Видео в кружок» (или `/circle`), затем видео. Бот вырезает квадрат по центру, приводит к 640x640 и отправляет как кружок. Длиннее 60 секунд обрезается. На слабом тарифе Render обработка может занять около минуты.

## Донат и Mini App

- Кнопка «💝 Донат» показывает три способа: DonationAlerts, ЮMoney и крипта (TON, адрес можно скопировать). Ссылки лежат в константах `DONATE_ALERTS_URL`, `YOOMONEY_URL`, `CRYPTO_ADDRESS` в начале `bot.py`.
- Кнопка «📱 Mini App» открывает приложение с теми же функциями, что и в боте: поиск (по названию, ссылке или загруженной записи), эффекты с тегами и обложкой, кружок, донат. Вкладка «Пост» есть у всех: если бот админ в твоём канале, появится выбор канала и форма публикации с кнопками, иначе приложение подскажет, как подключить канал. Готовые файлы приходят в чат с ботом.
- Страницу (`webapp/index.html`) и API отдаёт сам бот, поэтому нужен **Web Service** на Render. Адрес берётся из `RENDER_EXTERNAL_URL`, либо задай `WEBAPP_URL`. Без адреса кнопка не показывается.
- Все запросы Mini App проверяются по подписи Telegram (`initData`), поэтому API работает только для пользователей, открывших приложение из бота. Одному пользователю доступна одна задача за раз. Файлы до 40 МБ.

## Посты в канал

Настройки не нужны:

1. Сделай бота админом канала с правом «Публикация сообщений». Бот сам запомнит канал и напишет тебе, что он подключён.
2. Отправь боту `/post` (или нажми «📢 Пост в канал»), пришли пост, затем кнопки, проверь превью и опубликуй.

Если бот не запомнил канал (например, он перезапустился без Upstash), просто перешли ему один пост из канала, и он подключится снова. Если пересылка запрещена, напиши `@username` канала.

Функция для всех: у кого есть свой канал, тот и пользуется. Постить можно только в канал, где ты сам админ (Telegram проверяет это сам), чужой канал через бота использовать нельзя. Если у тебя несколько каналов, бот спросит, в какой публиковать. Сменить или добавить канал: `/channel`.

Формат кнопок: одна строка — один ряд, `Текст - https://ссылка`. Несколько кнопок в ряду разделяются знаком `|`.

## Рассылка (секретная команда)

Придумай длинный пароль и сохрани его в переменной окружения `BROADCAST_SECRET` на Render (в репозиторий пароль не пиши). Чтобы начать рассылку, отправь этот пароль боту обычным сообщением в личку: бот удалит сообщение и пришлёт ссылку на сайт-панель рекламы. Рядом есть кнопка «Рассылка прямо в чате»: пост, кнопки, превью, подтверждение.

- Получатели: все, кто запускал бота. Тот, кто заблокирует бота, автоматически удаляется из списка.
- Скорость около 20 сообщений в секунду, заблокировавшие бота пользователи удаляются из списка. По окончании бот присылает отчёт.
- Используй рассылку аккуратно: массовая реклама может вызвать жалобы, а Telegram ограничивает такие аккаунты и ботов.

## Реклама через сайт

Рассылку удобнее делать на веб-странице: открой `https://адрес-твоего-сервиса.onrender.com/admin` и введи пароль (значение `BROADCAST_SECRET`). Там текст (поддерживает `<b>`, `<i>`, `<a href>`), фото, видео или файл, кнопки и тестовая отправка на твой Telegram ID (его показывает команда `/id`). Кнопка «Отправить всем» запускает рассылку, а страница показывает прогресс и итог. Пароль проверяется на сервере, после 5 неверных попыток IP блокируется на 15 минут. Адрес панели не помнишь? Отправь боту пароль обычным сообщением, и он пришлёт кнопку-ссылку на панель.

## Хранилище (Upstash Redis)

Список пользователей и подключённые каналы нужно где-то хранить. На бесплатном Render файлы пропадают при каждом перезапуске, поэтому подключи бесплатный Redis:

1. Зарегистрируйся на [upstash.com](https://upstash.com) и создай базу Redis.
2. В разделе REST API скопируй `UPSTASH_REDIS_REST_URL` и `UPSTASH_REDIS_REST_TOKEN`.
3. Добавь обе переменные в Render и перезапусти сервис.

Без Upstash всё работает, но данные сбрасываются при перезапуске (рассылка дойдёт только до тех, кто писал боту после него).

## Локальный запуск

Нужны Python 3.10–3.12, [ffmpeg](https://ffmpeg.org/download.html) в PATH и токен от [@BotFather](https://t.me/BotFather).

```bash
python -m venv venv
source venv/bin/activate        # Windows: venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env            # заполни переменные
python bot.py
```

## Деплой на Render

В проекте есть `Dockerfile` (с ffmpeg) и `render.yaml`.

1. Залей репозиторий на GitHub (`.env` в него не попадёт).
2. На [render.com](https://render.com) создай сервис с runtime **Docker** (Background Worker или Web Service).
3. Добавь переменные окружения `BOT_TOKEN`, `CHANNEL_ID`, `ADMIN_IDS`.
4. Deploy.

Бесплатный Web Service засыпает через 15 минут без запросов: настрой пингер (например, UptimeRobot) на адрес сервиса. Бот сам поднимет мини-сервер на порту из `PORT`.

### Откуда бот берёт аудио

Сначала ищет на YouTube, затем на SoundCloud. Если один источник не работает (например, YouTube блокирует сервер), бот сам пробует следующий. Порядок задаётся переменной `SEARCH_SOURCES` (например, `soundcloud,youtube`). Если скачать не вышло, бот пишет причину ошибки.

### Если YouTube не даёт скачивать

Серверные IP часто блокируются (ошибка `Sign in to confirm you're not a bot`). Решение: экспортируй `cookies.txt` из браузера (расширение «Get cookies.txt LOCALLY»), загрузи его в Render как **Secret File** с именем `cookies.txt` и добавь переменную `COOKIES_FILE=/etc/secrets/cookies.txt`. Не публикуй этот файл на GitHub.

## Ограничения

- Telegram не даёт боту скачивать файлы больше 20 МБ и отправлять больше 50 МБ.
- Треки длиннее 10 минут бот не скачивает.
- Если ссылки перестали скачиваться, обнови yt-dlp (на Render достаточно пересобрать образ).
- Сессии хранятся в памяти: после перезапуска старые кнопки перестанут работать.
- Пост поддерживает одно сообщение (альбомы из нескольких фото не копируются).
- Распространение чужих треков может нарушать авторские права, а канал и хостинг могут получить жалобы. Ответственность на владельце бота.
